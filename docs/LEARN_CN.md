# 第一课到可独立修改：C++ / OpenGL 学习路线

## 第一课：用一个孔学会输入、计算和验证

Windows 在仓库里运行：

```powershell
.\run.ps1 -Mode Test
.\run.ps1 -Mode Demo
```

程序打开后按 `2`。第一个孔中心 x=6 mm、半径 5 mm，左边剩余距离为 `6-5=1 mm`；要求是 3 mm，所以显示红色。

按右方向键四次，每次移动 0.5 mm。中心变成 8 mm，剩余距离 `8-5=3 mm`，刚好满足要求。

按 `E`，查看 `artifacts/viewer/report.json`，确认 `geometry_passes` 与屏幕一致。这才是一条完整的工程链路：**输入 → 算法 → 可视反馈 → 可保存证据**。

### 现在只读三处

1. `geometry.hpp` 中的 `Hole`：孔由编号、中心和半径组成。
2. `geometry.cpp` 中的 `edge_clearance`：为什么要检查四条边并取最小值？
3. `analyze`：为什么实际间隙与规则阈值分开存放？

**亲手练习：** 把 `examples/edge_failure.scene` 第一孔的 x 从 6 改到 8，运行 CLI，比较退出码和 JSON。之后改回去。不要一开始就背整个 OpenGL 文件。

## 第二课：学会这个项目里真正使用的 C++

- `struct`：表达工程数据，不把所有参数写成无意义的数组下标。
- `std::vector<Hole>`：管理数量可变的孔。
- `const Scene&`：只读地引用场景，避免复制整个数据集合。
- `enum class FindingKind`：让不同违规类型有明确名字。
- 异常：把非法输入与“合法输入但不满足制造规则”区别开。
- 头文件与源文件：公开 API 与实现分开，CLI 和 OpenGL 共用核心。

练习：给规则增加一个最大孔半径限制。修改数据结构、分析函数、报告和测试；不要只在界面上染色。

## 第三课：几何计算

孔对矩形边界的最小间隙：

```text
min(x, y, plate_width-x, plate_height-y) - radius
```

两个孔之间的间隙：

```text
sqrt((x1-x2)^2 + (y1-y2)^2) - radius1 - radius2
```

负值表示相交或穿出边界。为什么不能只比较孔中心距离，而忽略半径？为什么规则阈值 3 mm 不应写死在算法里？

本项目逐对检查孔，复杂度为 O(n²)。小规模场景可读、可测试；当孔数变大，才考虑空间索引等广相位过滤。

## 第四课：从毫米到像素

工程坐标 Y 向上，屏幕像素 Y 向下，所以变换里有一次符号反转。

`View2D` 提供正向和逆向变换。鼠标选择先把屏幕坐标变回世界坐标，再用解析圆判断是否落在孔内。

练习：画出一个孔中心在平移、缩放前后的像素位置。看测试如何验证往返变换，以及缩放时指针下的世界位置保持不变。

## 第五课：理解 OpenGL 绘制管线

读 `viewer.cpp` 中两段 shader，再看 `Vertex`：每个顶点包含 x、y 和 RGB。

```text
场景毫米坐标
  → CPU 生成三角形／线段顶点
  → VBO 上传
  → VAO 描述 position / colour 布局
  → vertex shader 应用 mat3 正交视图变换
  → 图元组装、裁剪、光栅化
  → fragment shader 输出颜色
  → framebuffer
```

不是“把 C++ 画的图片显示出来”。CPU 准备几何数据，GPU 通过 shader 执行顶点变换和片元输出。

练习：只修改 fragment shader，让输出变成灰度。随后恢复，再把合法孔的颜色改成蓝色。说明这两种修改分别作用于管线的哪一层。

## 第六课：资源和软件结构

`Renderer` 析构时释放 buffer、VAO 和 program；`Window` 析构时释放上下文与窗口。OpenGL 对象的释放必须发生在有效上下文仍然存在的时候，所以主函数中先创建窗口、再创建 Renderer，销毁顺序反过来。

核心几何库不依赖 OpenGL，因此没有显卡或窗口也能跑数学测试和导出报告。这个分层比把所有逻辑塞进鼠标回调更容易维护。

## 第七课：做一次自己的工程改动

1. 增加最小孔直径规则，同时修改解析、分析、导出和测试。
2. 显示两孔间隙的尺寸线，解释标注位置与解析计算值的关系。
3. 增加键盘修改半径，验证变化同时影响边距、孔间距、面积和报价。

完成后用自己写的中文说明回答：改了哪里、为什么、如何确认正确，以及当前仍不支持什么。

## 对照答案：第一课

- x=6、r=5，左间隙 1，低于 3；退出码 2，报价为 null。
- x=8、r=5，左间隙 3，等于规则允许值；该孔通过。
- 屏幕显示和 JSON 必须共用同一个分析结果，不能各自实现不同的判断。
- 改视图缩放不能改变几何毫米值，也不能改变分析结果。
