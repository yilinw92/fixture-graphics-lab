# References and boundaries

- [Khronos OpenGL registry](https://registry.khronos.org/OpenGL/) and [Vertex Specification](https://wikis.khronos.org/opengl/Vertex_Specification) describe the graphics interfaces used by the renderer.
- [GLFW documentation](https://www.glfw.org/docs/latest/) is used for the Linux window/context adapter. GLFW is a build dependency on Linux, not vendored source. Windows uses native Win32/WGL.
- OpenGL headers and system libraries are provided by the compiler/OS development environment and retain their licenses.
- The geometry, examples, renderer, adapters, reports, tests and tutorials were newly authored with AI assistance. There are no employer designs, logos, photos or commercial prices.
- No code or assets from the earlier CutPlan teaching scaffold are copied into this repository. The engineering theme is related; this implementation has its own bounded API and application.
